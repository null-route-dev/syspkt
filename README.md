# syspkt

Correlates system calls with network packets.

## What it is

syspkt is a tool for looking at system calls and network packets together. The idea is to show which system call sent a packet, and which packet woke up a process.

## How it works

It watches syscalls and packets at the same time and tries to match them. The goal is a single timeline of system and network events.

Early development. Features, commands and limitations are not final yet.
